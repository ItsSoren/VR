Mode PC. Pour la VR, ouvrir en HTTPS sur le casque.

VR : pousse avec les mains. Stick droit : rotation à 45°. Grip : saisir. B/Y : réglages. A : Tool Gun, clic stick droit : action suivante.

PC : ZQSD ou WASD, Maj pour courir, Espace pour sauter. Glisse pour regarder. E : saisir ou interagir. F : créer un cube. G/T : outil et mode. X : pistolet. Clic ou J : tirer. Tab : réglages.
Mobile : glisse à gauche pour marcher et à droite pour regarder.
