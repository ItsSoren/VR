# VALLON — Les terres tranquilles

Ouvrir `index.html` sur PC, ou charger le site HTTPS depuis le navigateur du casque et sélectionner **Entrer en VR**.

En VR, appuie les mains virtuelles contre le sol ou un obstacle et pousse pour te déplacer. Le joystick droit tourne par crans de 45°. Les mains suivent les manettes. Le minage et la construction d’origine sont disponibles sur PC.

GitHub Pages : publier `main` depuis `/ (root)`.
